# Севрвис авторизации
Сервис авторизации представляет собой инструмент, который позволяет пользователям аутентифицироваться и получать доступ к защищенным ресурсам. Здесь описаны основные функции и возможности сервиса авторизации и интсрукции к его использованию.


Поведение по-умолчанию приведено ниже, в случае, если вам необходимо изменить его см п. `Кастомное поведение`
---

## Дефолтное поведение
Описание стандартного поведения сервиса авторизации

### Регистрация
По умолчанию регистрация новых пользователей осуществляется из админки Django.  
`url` для регистрации новых пользователей: `admin/core/user/add/`

После чего пользователям выдаются учетные данные для входа

### Login
Вход в систему и получение токенов доступа доступны по следующему  api: `auth/login`
для входа необходимо в теле запроса указать:
- `Email`
- `Password`

В случае успешной авторизации будет получен токен и дата когда он истекает, помимо этого будет получена информация о пользователе
(пример дефолтного ответа ниже)
```json

    "user": {
        "id": 1,
```

### Logout
Для выхода из системы нужно отправить `POST` запрос на `auth/logout`
***Для выполнения этого действия нужно отпарвить токен в заголовке `Authorization`***

## Кастомное поведение

### Модель
- Зарегестрированный по умолчанию пользователь находится в `modules/core/models/user.py`, по необходимости вы можете добавить ему новое поведение
- При необходимости изменить методы `API` вы можете унаследоваться от стандартного `API` расположенного в `modules/auth_service/api/user.py` и добавить 
это поведение без внедрения в существующий код (***не забудьте обновить `urls`***)
